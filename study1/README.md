# Affect Under Constraint

A preregistered experiment: when an emotional state is injected into a small language model and the model is told to behave in a way that conflicts with it, is the state erased, suppressed, or passed through?

- `PREREG.md`: the question, design, and frozen predictions
- `config.yaml`: every parameter, frozen
- `prompts/`: all prompts, word lists, and openers
- `AGENTS.md`: rules and stages for the coding agent
- `STATUS.md`: live progress
- `DEVIATIONS.md`: anything that departed from the plan

Author: Arthur Su. Part of the Computational Psychodynamics series (Zenodo).
