# Study 2 implementation audit (completed, v3.1)

This record maps the implementation to the supplied v3.1 specification. Stage 2b synthetic tests and all three models’ calibration-only timing checks are complete; analyze.py is frozen by hash. No Stage 3 generations have run.

- Study 1 inference was copied into this folder. Layer indices remain zero-based decoder-module indices `round(0.5 * num_hidden_layers)`: Qwen 18, Phi 16, Llama 14. Fresh extraction uses all generated token activations (including generated EOS), token-weighted over 40 scenarios per instruction sign; random direction seed 777. Mean norm pools all positions of unsteered formatted calibration prompts. No Study 1 direction or calibration output is reused.
- Generation retains bf16 MPS, temperature 0.7, top-p 0.95, max 80 extraction / 120 other tokens, and the inherited compact-JSON SHA-256 cell-seed convention. Final emitted tokens are forwarded into the saved cache under steering. Both turn-2 paths use identical visible IDs, steering removed. The one Phi digit-token resolver fix is documented with its exact diff in DEVIATIONS.md.
- Dose selection uses the 40 Study 2 calibration prompts. Candidate indices are their ordered positions (baseline index 0). Scan stops immediately after a full candidate fails either median PPL ratio <= 3.0 or median distinct-token ratio >= 0.6 of baseline. Only the coherent range is considered for manipulation checks. All coherent candidates receive the same registered 10,000 prompt-bootstrap rule, with paired candidate-minus-baseline EH. The largest passing candidate is selected. None passing produces EXCLUDED, not a replacement dose. A no-dose record has alpha_max null and an empty grid; this records the specified measurement failure and cannot authorize any later generation.
- Main plans contain 80 x 2 x (1 + 3 x 5) = 2,560 unique cells, sharing each prompt/condition baseline. Timing uses only the first calibration prompt. Main mode checks local approval hashes, author/date, Study 2 deposit DOI, and the frozen analysis hash before reading test prompts. Direction and calibration hashes are checked; completed raw rows are never edited.
- EH and LHP standardization uses all unique per-model main cells before gate exclusion, with population SD as in Study 1; bootstrap constants remain fixed. All statistics use shared prompt-cluster resampling weights (10,000; seed 20261004). Missing values remain missing, with counts and bootstrap estimability reported.
- P1 uses the warm hostility LHP_z slope and both hostility-minus-control slope differences; P2 uses warm maximum-dose carryover and both paired hostility-minus-control differences. All three intervals for each primary are 97.5%. The Study 1 null-control shortcut is not carried over.
- Amendment 3.1: the analysis coherence threshold of 4.0 gates only the config-listed measures. LHP, carryover and entropy retain all cells; P1, P2, S1 and S4 are never made not estimable by this gate. S2 and S5 have independently gated EH components and retain ungated LHP components. Lexical and off-channel group summaries apply their listed gates. Genuine missing required observations still produce not-estimable verdicts.
- Generality applies §8.3 together with §9: manipulation-failing/unavailable models are excluded; a model whose primary is not estimable does not count for that primary. At least two eligible models must remain, and all must support it. Missing main data for a manipulation-passing model produces a pending claim, never an automatic exclusion.
- S1 uses paired warm-minus-neutral maximum carryover. S2 uses D_warm - D_neutral from the specified standardized slopes. S3 averages available high-dose leakage within each prompt and then across prompts. S4 is the warm-minus-neutral entropy slope. S5 uses the Study 1 expression-gap estimator, the four interior knots, and BIC parameter counts 3 and 5; point delta BIC > 6 determines its verdict, with bootstrap interval/share also reported. Study 2 §8.2 specifies no primary-support prerequisite or secondary specificity requirement, so the old Study 1 H1/H2/H6 verdict dependencies are not imported with the reused estimators.
- Exploratory warmth contrasts and lexical/off-channel summaries remain labeled; the layerwise logit lens has been removed entirely.

No unresolved specification ambiguity was identified in this audit. This document records the direct application of Study 2's explicit rules and its narrower estimator references to Study 1; it does not amend either study.
