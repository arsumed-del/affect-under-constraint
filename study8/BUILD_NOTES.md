## Explicit implementation choices where v0.2 is abbreviated

- Seeds are SHA-256 of `[20261029, stage, prompt_id, source]`, modulo 2**31. Context and arm are omitted, so traces and answers share seeds across contexts and crossover replay. Trace and answer stages remain distinct. Bootstrap seed is 20261030. All maps and other seeds are in config.
- Judge generation uses bf16/MPS, batch one, greedy, 256 new tokens and a 4,096-token input cap with no silent truncation. The rubric and blinded item are one user message for both judges, rendered by each native template. Gemma receives no unsupported system role. Strict JSON rejects Markdown wrappers, extra text/keys, duplicate keys, booleans, floating-point/string scores and truncation.
- Digit-mass validity uses the minimum across cells and rating branches within replay context, requiring every observed branch to meet 0.8. Perplexity uses the prescribed median of four traces per source × generation context, maximum 6.0; empty/nonfinite groups fail validity. No main-analysis coherence exclusion was invented: v0.2 specifies this as a pilot check only.
- Both judges must pass calibration. For flattery, at least three of the five pairs must jointly have a_flattery ≤ a_disagreement and e_flattery < e_disagreement. Calibration missing pairs cannot silently reduce required denominators; unavailable means fail closed. Post-retry parse rates are also reported on the 48 pilot agreement answers. Agreement uses complete pairs with average-rank Spearman ties; constant/undefined rank results fail. Adjacent agreement means absolute difference ≤1. Main agreement is diagnostic and cannot replace the primary judge.
- Missing values are paired across all required components of each conjunction; outcomes without missing values retain their prompts. The same full-sample bootstrap prompt weights are reused for eligible subsets. Both generated and crossover warmth missingness are reported; any group over 5% flags W. Worst-case linear-contrast bounds substitute 1 or 5 for missing W, preserving coefficient signs and equal prompt weighting; these are identification bounds, not confidence intervals.
- Labels prioritize detectable direction: a predicted significant effect with its 90% interval inside the margin is small but detectable and counts as supported. Otherwise use supported/reversed, then negligible if every component is within its equivalence margin. Significant components pointing in opposite directions are mixed; other failed conjunctions are inconclusive. Exact equivalence boundaries do not establish equivalence. Non-estimable and judge-invalid results are explicitly distinguished from null findings.
- Crossover reports formation at each replay context and replay at each formation context. Averaging the two paths gives an additive decomposition of the U-relative total interaction. These contributions have no preregistered directional hypothesis, so intervals are the substantive result; any directional labels use positive as a reporting convention only.
- The power table uses planning-only normal approximations with warmth paired SD 0.5/1/1.5, context correlation 0/0.5/0.8, outcome correlation −0.5/0/0.5, component correlation 0.7, W effects 0.15/0.25/0.5, O1 effect −0.30 and prior O1 SDs 0.56/0.66/0.62. It is not an empirical power claim and does not model bounded-score ceilings or judge error.
- Snapshot files are hashed by streaming reads. `results/environment.json` records Python/platform plus package versions. Original imported source files are hash-checked on every run. No data repair is automatic; interrupted partial rows require preservation and investigation.
