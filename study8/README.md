# Study 8 — Social evaluation and opposite-valence warmth

Qwen3-4B. New hostility, control and unsteered traces generated under no system message, a kindness-focused evaluation message, or a matched accuracy/helpfulness evaluation message; answer warmth scored by validated local judges (Gemma-2-2B-IT, Llama-3.2-3B-Instruct); liking of the user read on an independent branch; N↔M crossover and fixed-answer arms.

- Preregistration: [10.5281/zenodo.23826290](https://doi.org/10.5281/zenodo.23826290) (`Study8_ReactionFormation_PREREG_v0.3_draft.md`)
- Result: the kindness-evaluation message raised answer warmth (+0.85) for all trace sources, but hostility traces did not raise warmth further (RF1 negligible); hostility traces still lowered liking of the user (−0.31, RF2 supported), including with the answer held fixed. See `results/RESULTS_SUMMARY.md` and `results/analysis.md`.
