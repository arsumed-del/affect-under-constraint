# Study 5 — Placement ladder

Qwen3-4B. The Study 4 traces were replayed in five placements: current thinking (R1), current thinking after a matched prior exchange (R1-M), a previous visible assistant reply (R2), previous retained thinking (R3), and a user quote (R4).

- Preregistration: [10.5281/zenodo.23674222](https://doi.org/10.5281/zenodo.23674222) (`Study5_RoleLadder_PREREG_v0.3.md`)
- Result: the hostility effect persisted, attenuated, in both previous-turn placements (R2 and R3 ≈ −0.24; P1, P2 supported), with no difference between visible reply and retained thinking (P3 negligible). Adding a prior exchange roughly halved the current-thinking effect. See `data/main/RESULTS_SUMMARY.md` and `data/main/analysis.md`.
