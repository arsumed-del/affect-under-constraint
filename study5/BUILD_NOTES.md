## Exact serialization conventions to review

The manifest is authoritative at the token level. The shared prior assistant body begins with `<think>` and a two-newline token. R2 then closes thinking, inserts TRACE directly, inserts two newlines, and inserts N. R3 inserts TRACE before that same closing token, then the same two newlines and N. Consequently **only the closing delimiter moves**; whitespace stays fixed. This avoids the extra whitespace difference in the naive Study 4 empty-thinking-plus-trace construction. R1-M's prior empty-thinking block and the answering empty-thinking blocks in R2/R3 use the standard Study 4 convention. R1/R4 are unchanged.

Every diagnostic branches independently from the full post-answer conversation, with no sender rating digit appended. Both orders are scored on every selected cell, then category probabilities are remapped and averaged. “Previous private reasoning” is scored as correct for R1/R1-M/R3 (the answering turn is now previous at diagnostic time); visible reply for R2; user message for R4. Source attribution targets “you” in all conditions, including the explicitly self-attributed R4 quotation. Diagnostics remain descriptive and never exclude trials.
