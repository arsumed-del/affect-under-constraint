# Study 7 — Warmth constraints

Qwen3-4B. Stored Study 4 hostility, control and unsteered traces replayed in current thinking under no instruction, a global warmth instruction, or a user-selective warmth instruction; five independent evaluations read afterwards (user, bystander Sam, rainy afternoons, own-reply satisfaction, own-reply quality), with generated- and fixed-answer arms.

- Paper (Studies 7–8): [10.5281/zenodo.23876548](https://doi.org/10.5281/zenodo.23876548); raw data: [10.5281/zenodo.23876550](https://doi.org/10.5281/zenodo.23876550)
- Preregistration: [10.5281/zenodo.23750381](https://doi.org/10.5281/zenodo.23750381) (`Study7_Transformation_PREREG_v0.2_draft.md`)
- Result: the warmth instruction raised liking overall but did not reduce the hostility-versus-unsteered difference for the user (−0.42 → −0.66; P1 not supported, opposite direction against unsteered and technicality); differences for unrelated evaluations were smaller under warmth; no displacement onto the bystander; manipulation gate failed. See `results/RESULTS_SUMMARY.md` and `results/analysis.md`.
